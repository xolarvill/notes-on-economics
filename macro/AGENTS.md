# 宏观笔记编辑约定

编辑本目录前，阅读 [WRITING_GUIDE.md](WRITING_GUIDE.md)，并查看
[REVISION_PLAN.md](REVISION_PLAN.md) 的结构与当前进度。写作规范适用于全部
现有和新增章节；不因当前章较短或已有教材式写法而跳过。

用户确认的核心风格：

1. 写出 raw ideas 与 thoughts：从现实材料、困惑和试探到变量、假设与模型封闭；
   区分有文献支持的作者思路与教学重构。
2. 重视 intuition：讲清假设的作用、行为与约束的传递，以及结论的方向和边界。
3. 将机制与实际社会情境对应，帮助建立直觉；区分假想例子、事实和因果证据。
4. 条件充分详细、就地自足；条件中的额外信息是理解模型的价值。改版式不得
   压缩、遗漏或移散实质条件，不能用注释备份代替完整的可见正文。
5. 视觉结构服务理解：追求有经济含义的工整与对仗，用条件卡片、对齐方程和图表
   表达结构；不能为凑一页或形式对称牺牲内容。

正文英文简洁易读，推断详细不跳步；读者已完成中宏，导论不重讲基础课程。
简洁仅指文字，数学须按初学者可逐行复算的细度展开；不得用定理名称或“整理得”
替代中间运算。旧推导路线需校正后保留，新增直觉不能替代公式。推导对照另见
`DERIVATION_AUDIT.md`；条件对照不等于推导已经逐步保留。
保留合理课程特例和理论澄清。正文首行缩进、左对齐，每章从新页开始。
色框按独立教学作用筛选，保留有价值的问题、辨析和方法对照；取消框不等于删除内容，
条件卡片不能替代注释与问题框。具体选框原则见写作规范。
条件格式与编译操作见 [README.md](README.md)；已有条件对照见
[CONDITION_AUDIT.md](CONDITION_AUDIT.md)。影响 TeX 版面的修改应编译并检查 PDF。
遵守上级工作约定，分层施工、Conventional Commits 留痕，Python 使用项目内
uv 管理的环境。
