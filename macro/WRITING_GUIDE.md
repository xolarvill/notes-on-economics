# 宏观笔记的写作与视觉规范

这是整本宏观笔记的长期规范，适用于修订旧章和新增章节。它记录用户在
Solow、Harrod--Domar 和 Ramsey 修订中确认的风格，不局限于这几个模型。
`REVISION_PLAN.md` 记录结构与施工进度，`README.md` 说明文件与编译方法；
后续写作以本文件为风格依据。

## 定位：语言简洁，理解过程充分

读者已完成中级宏观，正进入研究生宏观。正文使用简洁、自然、易读的英文，
但推导和条件要足够详细，不跳过影响理解的中间环节。简洁应来自准确措辞、
有序组织和清楚的层次，不能来自删掉条件、机制或必要推断。

导论只完成从中宏到高宏的过渡，不重讲中宏，也不预先塞入后面各章的方法细节。
模型章则应充分解释本章真正新增的机制。条件中的额外信息、思考过程和现实
关联本身就是笔记的价值，不按普通教材的简写习惯删去。

## 1. 写出 raw ideas 与 thoughts：模型怎样从问题中长出来

不仅交代“这个模型研究什么”或模型的历史地位，还要呈现面对材料时的思考：
看到什么事实或矛盾，原先会怎样猜，哪里让人起疑，可以尝试什么解释，哪项
限制使原有解释失效，最后为何选择这些变量、假设与调整机制。

让读者看见从未整理的材料到可分析问题的过程：为什么选资本强度而不是总量，
为什么把储蓄作为给定规则或选择变量，为什么暂时固定某个机制，又怎样补上
目标、约束、时序与出清条件来封闭模型。适当保留有启发性的试探与被放弃的
解释，并说明放弃的理由；不罗列与理解无关的所有可能路线。

这是一种可供读者复现的教学思路重构。只有有原始文献支持时，才把具体思想
过程归于作者；区分历史记录、文献中的论证和我们用于教学的推演，不虚构作者
的私人想法。结构随问题变化，不把每章机械写成同一套问答。

## 2. 重视 intuition：从假设到机制，再到结果

重要假设要说明它允许、排除或固定了什么，以及这为何有助于隔离本章机制。
关键方程要解释其经济含义，关键推导要说明正在求什么、为何走这一步。
结果之后讲清哪个主体改变了什么行为，通过哪条约束或价格关系传递，为什么
得到这个方向，以及换一个条件后结论可能怎样变化。

公式与直觉互相校验。必要时用边际实验、反事实、极端情形或小算例，让读者
自己判断符号和方向。避免只在章首加一段动机、章末加一段泛泛解释，中间仍
让读者独自补齐推断。并非每一步代数都需要长解释，但不能把经济假设、变量
重定义和代数变换藏在同一个箭头里。

## 3. 与实际社会关联，帮助建立直觉

在机制出现的地方接入可辨认的家庭、企业、政策或社会情境：例如暂时收入
损失下的消费调整、灾后资本重建、投资扩张、税收激励、人口变化或信用约束。
说明现实情境的哪些部分对应模型中的变量、冲击与行为，哪些部分被模型省略。
现实联系要帮助理解具体机制，不能成为与推导无关的时事装饰。

区分帮助理解的假想情境、自拟数值例子和有资料支持的事实。对具体社会现象
的解释应写出适用条件与证据边界；模型里的比较静态不是经验上的因果识别。
涉及实际数据、历史过程或政策效果时核对来源和时期，不用直觉替代证据。

## 4. 条件写得详细：条件本身承担教学任务

模型设定应让读者在本章内读懂谁拥有、谁选择、谁支付、谁承担约束，以及这些
关系如何构成均衡。根据模型列清以下内容，不以固定卡片数量代替完整性：

- 经济部门、商品、开放程度，主体的数量、同质性或异质性，企业与资产所有权。
- 初始禀赋、状态变量、外生路径与参数范围；技术的形式、性质、可用性及成本。
- 决策时点、信息集、状态与控制变量；家庭或企业的目标、预算和其他约束。
- 人口与劳动供给、收入各组成、价格与回报的口径，利润如何分配。
- 市场结构、要素供求和商品出清的明确条件，所需的偿付及终端限制。
- 一般设定与课程特例、归一化、连续与离散时间的关系，以及结论所需的附加条件。

每项不仅列标签；在有理解增益时，写出数学条件、经济解释及其作用。明确区分
竞争、同质性、代表性、优化和出清，不能当作同义词。不要用“同 Solow”或
“标准假设”等概括替代本章需要的完整设定。可以回指较长证明，但设定本身
不能要求读者翻回前章才能拼全。

改视觉格式之前，逐项建立原条件与新位置的对应关系。不得为了凑卡片、对齐
高度或塞进一页而删减、概括或把条件移散到求解过程。后文的解释与推导不能
替代条件部分应明确列出的内容。用户要求保留的原文应以注释等方式保留，
同时核对实际排版出的正文；注释里的完整不等于读者看到的完整。

保留合理教学简化，写明适用条件。发现理论或数学问题，说明与原课程表述的
区别，再作必要澄清；不把修正错误与压缩内容混为一谈，也不为保留原句恢复
已经确认不成立的表述。Solow、Ramsey 的逐项记录见 `CONDITION_AUDIT.md`。

## 5. Visually structured：用视觉结构表达经济结构

工整、对仗和层次感是帮助读者建立直觉的方式，不只是美化。相同层级采用
一致的标题、编号和方程对齐方式；主体、目标、约束、选择和均衡之间的关系
应能从版面上辨认出来。可比较的内容尽量用平行结构呈现，例如家庭与企业的
问题、原模型与扩展、冲击前后或稳态与过渡路径。

条件采用有意义的标题和编号卡片；信息完整时可用双列，需要展开时采用宽卡片，
在卡片之间自然分页。内容超过一张卡片的容量时按经济含义拆分。不得强迫本来
不同的机制对称，也不得为了视觉对称补入空话。先保全经济关系，再选择版式。

长推导按目标和阶段分组，适当使用对齐方程、机制图、时序图、表格和相图。
时序图必须符合真实的信息和选择顺序；图中的方向、坐标和适用条件须与正文
一致。色框保留三色与左侧竖线的共同语言，颜色不能代替标题或逻辑层级。

正文保持首行缩进和左对齐，每章从新页开始，章内小节自然衔接。标题应与首段
或首卡同页；短卡保持完整，长色框允许有清楚的跨页续接，避免边线与底色断裂。
影响版面的修改须编译并检查实际 PDF，不能只凭 TeX 源码判断效果。

## 推导与修订的共同要求

保留原有的详细推断标准：明确目标与约束；关键变形交代依据；保持时间下标、
条件期望和信息集；区分恒等式、最优条件、均衡条件和政策规则，区分精确结果、
局部近似与特例，区分水平、增长率、稳态与过渡。新符号或口径变化当场说明。

章节结构服从问题，不机械套用模板。开头让读者理解为何需要新模型，末尾简短
交代其解释范围及下一机制为何必要。新增 raw thoughts、条件解释、现实关联
应推进理解，避免同一解释在卡片、正文和章末反复出现；但“去重复”不能成为
删除实质条件和必要推导的理由。

修订完成后检查：读者能否复现建模的思路，读懂完整条件，跟上推断，用现实
情境解释机制，并从视觉结构中看出各部分的关系。分层施工并用 Conventional
Commits 留痕；不要将尚未完成的章节写成已完成。
